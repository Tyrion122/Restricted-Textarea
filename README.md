# 📝 Restricted Textarea (Character Counter)

A dynamic text input component built with **Vanilla JavaScript**. It features a real-time character counter that visually updates as the user types and enforces a maximum character limit, similar to features found on social media platforms (like Twitter/X).

### 🚀 Live Demo
👉 **[Click here to view the project live](https://tyrion122.github.io/Restricted-Textarea/textarea.html)**

---

### 🛠 Tech Stack
* **JavaScript (ES6+)**: Logic for character counting and input validation.
* **CSS3**: Styling for the textarea and visual limit indicators.
* **HTML5**: Structural elements.

### 💡 Project Focus & Key Concepts
This project highlights interaction with form elements:
* **Input Events**: Utilizing the `input` event to trigger functions on every keystroke.
* **String Manipulation**: Real-time calculation of string length (`.length`) to update the UI.
* **User Constraints**: Preventing further input once the maximum limit is met to ensure data integrity.
* **Conditional Logic**: Dynamically changing CSS classes (e.g., changing colors) when the character limit is approached or reached.
